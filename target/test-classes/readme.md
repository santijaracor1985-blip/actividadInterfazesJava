Sistema de Espacios Culturales Medellín

Descripción
Este proyecto en Java representa diferentes espacios culturales de Medellín utilizando una interfaz. Se aplica programación orientada a objetos, especialmente el uso de interfaces y polimorfismo.

Se creó una interfaz llamada EspacioCultural que define métodos comunes para todos los lugares. Luego se implementan varias clases que representan espacios reales como el Jardín Botánico, el Museo de Antioquia y el Parque Explora.

Estructura del proyecto
El proyecto contiene los siguientes archivos:

EspacioCultural.java: interfaz con los métodos principales
JardinBotanico.java: clase que implementa la interfaz
MuseoDeAntioquia.java: clase que implementa la interfaz
ParqueExplora.java: clase que implementa la interfaz
Main.java: clase principal que ejecuta el programa

Funcionamiento
En la clase Main se crea una lista de tipo EspacioCultural donde se almacenan los diferentes espacios. Luego se recorre la lista con un ciclo for-each para mostrar la información de cada lugar.

El programa imprime en consola el nombre, horario, requisito de entrada y actividad principal de cada espacio cultural.

Ejemplo de salida

Lugar: Jardín Botánico
Horario: 9:00 AM - 4:30 PM
Requisito: Entrada libre (algunos eventos requieren registro)
Actividad: Caminando por el Bosque Tropical...
----------------------------------------------

Objetivo
El objetivo de este proyecto es practicar el uso de interfaces, polimorfismo y listas en Java.
